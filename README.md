# マークダウン変換アプリ

テキストをマークダウン形式で表示するWebアプリケーションです。リアルタイムプレビューとコピー機能を備えています。

## 機能

- **リアルタイムプレビュー**: 入力したテキストが即座にマークダウン形式で表示されます
- **コピー機能**: 変換されたHTMLをワンクリックでクリップボードにコピーできます
- **レスポンシブデザイン**: PC、タブレット、スマートフォンで快適に使用できます
- **見やすいUI**: 2カラムレイアウトで入力と出力を同時に確認できます

## 使い方

1. `index.html` をブラウザで開きます
2. 左側のテキストエリアにマークダウン記法でテキストを入力します
3. 右側にリアルタイムでプレビューが表示されます
4. 「コピー」ボタンをクリックすると、変換されたHTMLをクリップボードにコピーできます

### キーボードショートカット

- `Ctrl/Cmd + S`: 変換結果をコピー

## サポートしているマークダウン記法

- 見出し（`#`, `##`, `###` など）
- 太字（`**太字**`）
- 斜体（`*斜体*`）
- リスト（`-` や `1.`）
- リンク（`[テキスト](URL)`）
- インラインコード（`` `code` ``）
- コードブロック（` ``` `）
- 引用（`>`）
- 水平線（`---`）
- テーブル
- 画像

## 開発者向け情報

### ローカルでの実行

このアプリケーションは純粋なHTML/CSS/JavaScriptで構築されているため、ビルドプロセスは不要です。

```bash
# ブラウザで直接開く
open index.html

# または、ローカルサーバーを起動
python -m http.server 8000
# http://localhost:8000 にアクセス
```

### カスタマイズ

- `style.css`: カラースキームやレイアウトを変更できます
- `app.js`: マークダウンの設定を `marked.setOptions()` で調整できます
